About LungCare AI

A clinical-decision support system combining multi-algorithm soft-voting ensembles with SHAP local explainability for early thoracic risk screening.

System Pipeline Architecture

The application runs end-to-end inference without third-party cloud analytics, preserving privacy and enabling deterministic execution:

1. Intake Layer
23 clinical parameters collected via 3-step structured wizard with strict type & boundary verification.
2. Preprocessing
Embedded SimpleImputer(median) and Winsorization range capping to eliminate data leakage.
3. Ensemble Engine
Soft-voting classifier combining RF, XGBoost, LightGBM, Logistic Regression, and SVM.
4. Explainability
SHAP TreeExplainer calculates marginal Shapley values for transparent factor ranking.

Technology Stack

Backend Framework
Flask 3.0 (Python 3.14), Gunicorn-ready WSGI, python-dotenv environment isolation.
Machine Learning
Scikit-learn 1.5, XGBoost 2.1, LightGBM 4.5, SHAP 0.46, Joblib model persistence.
Interactive Visuals
Chart.js 4.4 (Canvas gauges, radars, donuts, bars), html2pdf.js document synthesizer.
Design & Accessibility
Pure Semantic HTML5, CSS Variables (Dark/Light mode), Vanilla JS, Zero Node dependencies.

Dataset Background & Clinical Notes

The prototype was developed using the benchmark Cancer Patient Data Sets (1,000 observations across 23 phenotypic, lifestyle, and symptom features). As documented in our Model Performance Audit, this dataset exhibits high linear separability, resulting in 100% convergence across standard cross-validation splits. In real-world hospital environments, biological variance and measurement noise would yield lower empirical certainty.
