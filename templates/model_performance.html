🛡️ Data Preprocessing & Outlier Handling

To ensure production stability, prevent data leakage, and handle custom/noisy external datasets, the training and inference workflows employ an integrated scikit-learn preprocessing pipeline:

🧩 Missing Value Imputation
Strategy: SimpleImputer(strategy="median")
Implementation: Integrated directly into each estimator pipeline. If incoming patient data or custom datasets have null values, they are imputed using median values computed strictly from the training split.
📈 Outlier & Range Handling
Strategy: 1.5×IQR Statistical Screening + Domain Capping
Implementation: Likert symptom features (1–9) and Age (1–100) are bounded via Winsorization/clipping. Statistical IQR bounds are evaluated across all features to flag abnormal distributions.
🔒 Data Leakage Prevention
Strategy: Scikit-learn Pipeline Encapsulation
Implementation: Imputation and standard scaling statistics are learned only on the training fold during cross-validation, strictly isolating holdout test splits.

⚠️ Academic Limitations

  • Synthetic dataset: The underlying data is synthetic / near-perfectly separable, causing artificially high metrics that do not generalise to real patients.
  • No external validation: Results are from an internal 80/20 split and 5-fold CV only — no independent holdout or external cohort was used.
  • Not FDA/CE cleared: This system has not undergone regulatory review and must not be used for clinical triage or diagnosis.
  • Feature leakage risk: With near-separable synthetic data, some features may act as near-perfect proxies for the label, inflating test performance.
  • Demographic generalisability: No real demographic diversity was validated; model behaviour on under-represented groups is unknown.
  • Educational use only: This project is a proof-of-concept for academic demonstration purposes only.
